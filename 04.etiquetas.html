ETIQUETAS SEMÁNTICAS HTML


REGRESAR

header

Se utiliza para colocar el encabezado principal de una página o sección.

nav

Sirve para crear una sección de navegación con diferentes enlaces.

main

section

Permite organizar el contenido de una página en diferentes secciones.

article

Se utiliza para mostrar contenido independiente, como artículos o publicaciones.

aside

Contiene información adicional relacionada con el contenido principal.

search

Representa un área destinada a realizar búsquedas dentro de una página.

address

Se utiliza para mostrar información de contacto del sitio o autor.

footer

Representa la parte final o pie de página de un sitio web.
